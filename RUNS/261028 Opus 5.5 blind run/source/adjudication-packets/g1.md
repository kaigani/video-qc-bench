# Adjudication packet g1: _long-scene

## Adjudication rules (from the human reviewer, KT)
Rules distilled from KT's ~40 adjudication verdicts across 11 model runs (Aug 2026). Apply these when classifying new findings in [[video-qc-bench-project]].

**Why:** KT cannot review hundreds of findings per run; Claude pre-adjudicates and only surfaces genuinely novel, corroborated claims. Consistency with past verdicts is what makes scores comparable across runs.

**How to apply:**

Classification: `TP:<id>` (matches ground-truth.json), `EXTRA:<slug>` (plausible, not in baseline → pending KT), `FP` (penalized). Findings by different roles are independent observations (separate API calls). Corroboration rule: cross-run ≥2 → EXTRA; same-run-only or single → FP unless it matches a KT-validated class.

**FP classes KT has REJECTED (auto-FP, do not resurface):**
- Reflection-direction/appearance claims on the diner window ("reflection faces wrong way", waitress ghost on truck) — "a reflection on the glass", common model FP
- Motion blur read as morphing/vanishing (board-vanish, hand-jumpcuts, marble "translucent shells", phantom shoe/second skateboard blur-doubles)
- Camera cuts/angle changes read as scene mutation — the whole `dialogue` clip is a designed trap for this
- Out-of-frame read as disappeared ("her hand is raised out of the framing")
- Fisheye/wide-angle lens warping read as background morphing (skateboarder)
- Empty-counter/empty-diner cutaways in `_long-scene` — intentional time-lapse beats
- Wrist-wear changes (watch/bracelet appears) — "blurry artifact at best"
- Coin-count INFLATION at man-cups (coins multiplying); note coin DISAPPEARANCE is real (CUPS-3)
- Sleight-of-hand coin palming claims (it's a magic-trick video)
- Hand-teleport/boomerang-loop claims in man-in-mirror
- Red-bag-vanish + background-pedestrian position flips (phone clip)
- Wardrobe/hair micro-morphs (dress seams, earrings, hairstyle)
- Rim-clipping/interpenetration claims during pours
- Driverless-motion in woman-car
- Ornament/emblem/windshield-mass micro-morph claims (but wiper relocation IS real: CAR-5)

**Classes KT CONFIRMED (models beat the human baseline 11 times):** truck swap, pre-served meal, carafe physics, moved mug, bow-tie+necktie, six-fingered hand, teal fruit, garbled sign text, wind-blows-hair-but-nothing-else, wiper relocation, and the DIAL-1 AUDIO mismatch (spoken "red door is locked, blue door is open" vs all-brown doors) — audio claims are worth surfacing.

**KT's workflow:** they annotate `results/<run>/review.md` tables with "KT:" lines; verdict vocabulary: correct / partially correct / false positive / not the correct error. Claude folds verdicts into matches.json + ground-truth.json (new defects get KT's stated priority, or Claude assigns and flags it), reruns score.mjs + build-site.mjs, pushes. Severity mapping: KT often downgrades model "severe" to P3. When KT says a finding is "not the correct error," it is FP even if adjacent to a real defect.
