Rules distilled from KT's ~40 adjudication verdicts across 11 model runs (Aug 2026). Apply these when classifying new findings in [[video-qc-bench-project]].

**Why:** KT cannot review hundreds of findings per run; Claude pre-adjudicates and only surfaces genuinely novel, corroborated claims. Consistency with past verdicts is what makes scores comparable across runs.

**How to apply:**

Classification: `TP:<id>` (matches ground-truth.json), `EXTRA:<slug>` (plausible, not in baseline → pending KT), `FP` (penalized). Findings by different roles are independent observations (separate API calls). Corroboration rule: cross-run ≥2 → EXTRA; same-run-only or single → FP unless it matches a KT-validated class.

**KT's workflow:** they annotate `results/<run>/review.md` tables with "KT:" lines; verdict vocabulary: correct / partially correct / false positive / not the correct error.
