Video QC Bench

Can video language models find continuity and physics defects in AI-generated video? Five systems, each run as five specialist forensic observers plus a generalist baseline over 14 test clips, scored against a human reviewer's defect baseline. Specialists track narrow invariants (object persistence, character continuity, contact mechanics, spatial topology, causal order) instead of answering a broad “find any issues” prompt.

Leaderboard: detection credit vs false-positive penalty

Detection credit sums priority weights (P0=8 … P4=1) over unique human-baseline defects a model found; each false-positive finding costs 1 point. Findings that are plausible but absent from the human baseline (“extras”) are neutral.

      Method & caveats

      • Protocol: each role is an independent API call: role charter → invariant ledger → strict-JSON findings with timestamp, severity, and confidence. Same six prompts for every system; videos sent as base64.
      • Ground truth: a human reviewer's per-clip defect audit (P0 unusable … P4 minor), plus one deliberately clean clip (dialogue) as a false-positive trap. Gemini Pro fell into it 5 times; Flash and Pegasus resisted.
      • Adjudication: all 216 findings classified against the baseline by Claude (Fable 5), with frame-level spot checks via extracted contact sheets; borderline calls documented in ground-truth/matches.json.
      • Caveats: Qwen & Pegasus saw compressed variants of the 2-minute clip (provider size caps); the contact-role prompt was reworded mid-study after Alibaba's content filter rejected the word “penetration”; Qwen, Pro, and Gemma ran with reasoning enabled, Flash and Pegasus without.
      • Reproduce: node src/run-benchmark.mjs --model <id> → node src/score.mjs. Raw per-call JSON lives in results/<run>/raw/.
